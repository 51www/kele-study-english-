# Saylo

个人自用的英语口语练习 App：选一个场景，用英文对话，卡住时可以看翻译和提示，练完做一次复盘。Flutter 开发，交付形态是 Android App。

## 项目介绍

Saylo 是一个只给自己用的英语口语练习 App：**选一个场景，和 AI 一人一句聊 10 分钟；卡住时再看翻译和提示，练完只记 1–3 个真正要改的表达**，隔几天让这些句子自己回来找你。

- **形态**：Flutter 开发的 Android App（正式包名 `com.kele.saylo`）；Web 仅用于页面走查与构建验证，不作为交付形态。
- **面向**：单用户、A2–B1 水平、每次约 10 分钟、每周 3–5 次；不做账号、课程、考试备考、支付、社交、排行榜与云同步。
- **数据**：会话、复盘、表达本、教材与设置全部保存在本机；接口密钥存系统安全存储，界面只显示尾 4 位。
- **能力来源**：对话与翻译由使用者自填的 OpenAI 兼容接口驱动，语音识别可单独配置、未配置时用系统识别；朗读默认 Edge 在线语音，失效时自动降级为系统朗读。任一环节失败都有文字兜底，不会中断对话。
- **闭环**：场景 → 对话 → 复盘 → 到期复练；另有「把一段音视频变成逐句听写教材」作为独立练习线。


## 使用说明

1. **安装**：Android 真机安装 APK，或在本机 Chrome 里跑 Web 调试，命令见下方「运行说明」。
2. **先配模型**：「我的 → 设置 → 模型配置」填写接口地址、API Key、模型名称，点「测试连接」确认可用后保存。未配置时首页会给出提示；Key 只存本机，不回显明文。
3. **选配语音识别**：「设置 → 练习 → 语音识别配置」可填写独立的转写接口；留空则用系统识别。首次录音需要授权麦克风。
4. **开始练习**：从首页推荐卡或「全部场景」进入场景库 → 场景详情看角色、3 条目标与目标表达（可试听）→ 可选 60 秒热身 →「开始练习」。对话页按住麦克风说话、松开发送，也可一键切到文字输入。
5. **结束或续练**：「结束并复盘」生成本次复盘；「保存并退出」原样保留现场，之后可从首页「继续上次」、记录页或场景详情接着说。
6. **日常入口**：底部 4 个 Tab 为练习 / 记录 / 表达本 / 我的；首页还有「今天练这个」、3 分钟轻量练习、听写教材、方法 / 技巧等栏目。
7. **按需调整**：朗读引擎、音色 / 语速 / 自动朗读、难度等级、翻译默认方式、每日目标、月度成本提醒、听写判分规则；「数据与存储」可清理语音缓存或清空练习数据。
8. **前提与边界**：对话、识别、翻译与在线朗读需要联网；成本是本地估算而非厂商账单；Edge 在线朗读是非官方接口，可能失效并自动降级。数据只在本机，卸载或清空后无法恢复。

## 功能介绍

- **首页（练习）**：今日目标、本周有效次数与连续天数、上次卡在哪、继续上次；「今天练这个」按本地数据给出一条可直接开始的推荐，3 分钟轻量练习适合低能量日。
- **场景库**：内置场景数量与分类按实际数据展示（不写死数值），覆盖日常、工作、旅行、社交、健康、观点及更多生活任务分类，可搜索、显示练过次数；自建场景支持一句话生成或手填、编辑与删除。场景详情给出本场 3 件小事、目标表达试听与课前 60 秒热身。
- **对话**：按住说话 + 文字兜底，AI 每次 1–2 句、只问 1 个问题，回复可自动朗读、重听与停止；翻译三态（关闭 / 点按 / 常开双语字幕）、「我想说」中→英、就地展开的参考答案；每句回答可优化、回放原声、单独朗读，并有完成回答的鼓励动效。
- **复盘与记录**：1 个亮点 + 最多 3 条改法（原句 / 改进句 / 中文原因，附中式成因与日常、正式两版说法）+ 值得记住的表达 + 下次建议；支持目标自评、90 秒开口复述、改进句试听与删除、对话原文回看。
- **表达本与复练**：首次打开即有初始表达，可新增 / 编辑 / 朗读 / 删除 / 标记已掌握；改法、表达与错句统一进入 1 / 3 / 7 / 14 天的到期队列，复练中心一次只练一条，离线判对、不打分。
- **听写教材**：导入本地音视频 + `.srt` / `.vtt` 字幕（UTF-8 / GBK），或填写合法直链与播客 RSS；自动切句、逐句播放与 0.75x 慢速、逐词差异判分、错句本与「只练错句」。不抓取平台内容，只播音频不显示画面。
- **我的**：练习次数 / 今日开口 / 分钟数、本月成本估算与预算提醒、上一回合延迟、近 4 周「提示使用率 / 改法复现率」趋势（可查看计算口径），以及全部设置入口。
- **明确不做**：发音分数与等级、严格纠错、虚拟人、全双工打断、课程与考试题库、账号 / 订阅 / 云同步、多语言、平台下载器。

## 对话体验

一次练习由 AI 的一句简单开场白开始，之后按「你说一句、AI 回一句」推进：

1. **说话**：按住麦克风说完松手即发送，识别文本先显示出来；听不清或识别错了可以重说，也能立刻切到文字输入。录音与播放互斥，按下麦克风即停止朗读。
2. **回应**：AI 保持场景角色，用英文回 1–2 句并只问 1 个问题，回复可自动朗读；气泡上可重听、停止，跑题时会被温和拉回一次。
3. **翻译**：默认关闭，先练听力；点按某条消息看中文，或切到「常开」让每条 AI 消息下方带中文，英文始终是主显示。「我想说」把中文变成一句可直接说的英文，可编辑、可试听，但必须你自己发送。
4. **卡住时**：点「提示」就地展开一句参考回答（英文 + 一行中文对照），答案贴合当前话题与场景；不弹窗、不自动发送、不写进对话历史。「优化句子」给更自然的说法与中文理由，同样只展示，可试听或存入表达本。
5. **说完之后**：每完成一次回答有一次轻量鼓励动效；自己那句下面可回放原声（文字输入或无录音时会置灰说明）或单独朗读。纠错不在对话中打断，想看才展开句旁标记，课后集中给最多 3 条改法并用中文解释为什么这样改，没有分数与评级。
6. **看历史**：上滑浏览旧消息时不会被新消息拉回底部，回到底部或点「回到最新」才恢复跟随。
7. **中途离开**：消息、轮次、时长与成本原样保留，首页、记录页、场景详情三处都能续练；只有显式「结束并复盘」才生成复盘。上次没等到回复时给「重试」，不自动补发。
8. **出问题时**：识别失败转文字，朗读失败自动切系统语音或只显示文字并给「重试朗读」，接口错误按鉴权 / 模型或路径 / 限流 / 服务异常四类给可操作的下一步；难度、音色、语速、翻译默认方式都可随时调整。

## 运行说明

环境要求：

- Flutter 3.47.x（Dart 3.13.x），Android SDK 使用 Flutter 默认版本（compileSdk 36 / minSdk 默认）。
- Web 调试需要本机 Chrome；Android 构建需要可用的 JDK、Android SDK 与可访问 Maven 仓库的网络。

启动 Web 调试：

```bash
flutter pub get
flutter run -d chrome
# 或构建静态产物
flutter build web --release
# 受限网络下改用本地 CanvasKit（本项目验证过的命令）
flutter build web --release --no-web-resources-cdn --dart-define=FLUTTER_WEB_CANVASKIT_URL=canvaskit/
```

构建并安装 Android 真机（开发调试）：

```bash
flutter build apk --debug
adb install -r build/app/outputs/flutter-apk/app-debug.apk
```

 

构建正式包：

```bash
# Android：分 ABI 打包（推荐，单个包更小）；CI 已不再产出 universal 胖包
flutter build apk --release --split-per-abi
```

> `saylo-release.jks` 与 `key.properties` 必须一起离线备份：丢失后无法再为已安装的 App 提供可升级的包。旧的测试包 `com.kele.kele_speak` 与正式包是两个独立应用，数据不互通，可自行卸载。
