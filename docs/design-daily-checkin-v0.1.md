# 每日学习打卡 + 首页布局优化方案（建议稿）v0.1

- 文档状态：**已拍板（2026-11-13），决策见 §6；方案定稿，待实现**（本文只讲功能与方案要点，不含实现细节；落地后验收口径与任务见里程碑清单）
- 日期：2026-11-13
- 依据：需求文档 v0.2（§0.3 / §0.4 / §3.2）、学习路径方案（§2 红线）、UI 设计规范、现有 `home_page` / `me_page` / `app.dart` 路由与 `homeDataProvider` 实现
- 一句话：**把"今天练没练"做成首页一眼可见、可随手补记的打卡，并把首页散落的入口收拢成"今日 → 下一步 → 统一练习入口"三段式，让常用操作两步可达、不误触。**

---

## 1 现状与动机

| 已经具备 | 与打卡/布局的关系 |
|---|---|
| `homeDataProvider` 已按天聚合：今日分钟、今日轮次、本周次数、连续天数 `streakDays`、目标分钟 | 打卡"自动判定"直接复用，无需重复统计 |
| 首页 `streak`（TopBar 与 Me 页两处）已是中性"连续 N 天"展示 | 打卡体系落点，不新增游戏化元素 |
| 学习类型已存在：口语对话、听写、复练、3 分钟轻量 | 自动打卡的活动来源 |
| 底部 4 Tab 锁死（首页/历史/表达本/我的），多处约定"不改" | 打卡不能做成第 5 个 Tab，只能进首页或独立页 |
| 红线（需求 §0.4 / 路径方案 §2）：不做连胜/勋章/排行榜/每日推送/分数等级 | 日历打卡必须落在这条线内 |

**首页布局现有问题（用户反馈"按钮布局需优化"的根因）：**

1. 区块顺序乱：`GoalCard`(今日分钟) → 本周说明 → 下一步 → 轻量按钮 → 场景练习 → 上次卡在哪 → 继续上次/最近练习 → 方法技巧 → 听写教材。首屏焦点分散，信息层级不清。
2. 入口形态混用：有的用整卡（`TodayPracticeCard`）、有的用 `SecondaryButton`（轻量）、有的用区块（`_TipsEntry`/`_DictationEntry`），视觉噪声大。
3. 记录类卡片（卡在哪/继续/最近）挤在首页，但 `history` Tab 已能承载，造成重复与首屏冗长。
4. 主色实心 CTA 出现多处（下一步"开始"是 Primary、GoalCard 是渐变主色卡），与"一屏一个主色 CTA"的规范有出入。

## 2 定位与边界

| 是 | 不是 |
|---|---|
| 在首页常驻"今日打卡"状态 + 一张月度日历，记录每天学了什么 | 连胜、勋章、排行榜、积分、等级、百分比 |
| 用"今日待打卡"状态 + 连续天数自然督促 | 每日推送、系统提醒、强制任务 |
| 复用 `session` 聚合统计连续天数与目标进度 | 新建一套独立统计、重复计数 |
| 把首页入口收拢为统一列表/网格，缩短操作路径 | 改底部 4 Tab、新增 Tab、重排导航结构 |
| 允许用户把 App 外的学习（背单词/影子跟读）补记进当天 | 把 App 外活动当作核心指标、或强制要求 |

**口径冲突先说清：**

- 需求 §0.4 与路径方案 §2 把"打卡/补作业/勋章/排行榜/每日推送"列为范围外。本方案以**中性记录 + 自然督促**落地，恰好避开：连续天数沿用现有 `streak`（中性统计），日历只展示"哪天练了/练了什么"，不发通知、不给徽章、不排名。
- 若用户想要"断签补卡积分商城/连续奖励弹窗"等游戏化，属于**范围变更**，须先修订口径再实施。
- 底部 4 Tab 保持不变；`history` 页承载全部练习记录，承接从首页移出的"继续/最近/卡在哪"。

## 3 打卡的定义与记录方式

### 3.1 两种来源

- **自动打卡（核心）**：当天在 App 内完成任意一次有效学习活动即记为"已打卡"。有效活动 = 产生 `session` 记录的活动（口语对话、听写、复练、3 分钟轻量）。直接复用 `homeDataProvider` 的按天聚合，与现有 `streak` 同源同口径。
- **手动补记（可选，呼应"背单词/影子跟读"原始诉求）**：用户在首页打卡模块勾选"今天还做了：背单词 / 影子跟读 / 其它"。纯本地存储，**不依赖模型密钥、断网可记**；勾选即视为当日已打卡，丰富日历展示，但不计入"每周 ≥3 次、每次 ≥8 分钟"主指标（与轻量同口径）。

### 3.2 打卡"完成"判定

```
当日已打卡 = 当天存在有效 session 聚合活动
          OR 用户在当日手动勾选了任一补记项
```

- 自动部分由 `session` 表按天聚合（与 `streakDays` 同一游标逻辑），无需新增表。
- 手动补记需要按天持久化历史，新增一张轻量 Drift 表：

```text
daily_checkin
  date          TEXT PRIMARY KEY   -- 'YYYY-M-D'（本地时区当天）
  extra_types   TEXT               -- 逗号分隔：vocab/shadow/other
  note          TEXT               -- 可选一句话备注
  updated_at    INTEGER            -- 毫秒时间戳，用于排序与去重
```

> 仅手动补记进表；自动活动仍从 `session` 派生，保证"连续天数"口径唯一、稳定。

## 4 展示方式

### 4.1 首页"今日"主卡（核心新增，替换现有 GoalCard + 散落 streak 文案）

整合为一张白/渐变主卡，自上而下：

1. **打卡状态行**：大号状态「今日已打卡 ✓」/「今日待打卡」，右侧中性展示「连续 N 天」（复用 `streakDays`，火焰图标，不做勋章）。
2. **今日学习构成**：一行 chip——口语 / 听写 / 复练 / 轻量 / 背单词 / 影子跟读；已做的亮起（主色实心或浅紫底+主色描边，符合规范 Chip 选中态），未做的灰。点 chip 不跳转、仅本地切换（防误触）。
3. **目标进度**：保留现有"今日分钟 / 目标分钟"进度条与本周次数，作为次级信息收进卡内，不再单独一张渐变卡。
4. **唯一主色 CTA**：
   - 今日未打卡 → 「开始今日学习」（跳转下一步/场景库）。
   - 今日已打卡 → 「看打卡日历」（跳转 `/checkin`）+ 正向文案。

> 一屏只保留这一个主色实心 CTA；轻量练习、场景等入口改为下方统一列表，不再占用主色按钮。

### 4.2 打卡日历页（新增 `/checkin`，ShellRoute 外，与 `/retention` `/quick` `/path` 同级）

- **月度网格**：标记每天是否打卡（主色实心圆点 / 浅底），点击某天展开当日学习构成明细（活动类型 + 时长 + 备注）。
- **顶部统计（中性）**：本月打卡天数、当前连续、最长连续。**不展示分数/等级/百分比/排名**。
- **补记入口**：选中"今天"可勾选背单词/影子跟读/其它并写备注，与首页打卡模块共用同一张表与组件。
- **断网可看**：全部本地数据，无模型/联网依赖（沿用路径需求"断网可看"精神）。

## 5 布局优化方案（重新梳理按钮布局）

原则：**保留全部核心功能，首页聚焦"今日 + 下一步 + 统一练习入口"，记录收到 `history`，两步可达、不误触。**

### 5.1 首页三段式重组

| 区 | 内容 | 形态 | 去留 |
|---|---|---|---|
| **今日**（顶部主卡） | 打卡状态 + 连续天数 + 学习构成 + 目标进度 + 唯一主色 CTA | 整合主卡（见 §4.1） | 合并 GoalCard 与散落 streak；目标进度降级为卡内次级 |
| **下一步** | 今天练这个 / 下一步（路径驱动 `NextStepCard`） | 保留现有卡 | 不变，仍是主行动建议 |
| **练习入口**（统一） | 场景库 / 复练 / 3 分钟轻量 / 听写教材 | 统一 `AppListTile` 列表（图标+标题+副标题+chevron，≥56 高） | 把原"轻量 SecondaryButton"、"方法/技巧区块"、"听写区块"统一为列表入口；场景推荐卡下移到此处或保留 2 张推荐 |
| **资源**（可选轻量） | 方法 / 技巧、学习路径 | 同款列表入口 | 路径入口与 `me` 页去重，首页保留其一 |

- **从首页移出**：「上次卡在哪」「继续上次」「最近练习」三块 → 全部并入 `history` 页（`history` 已存在，天然承载记录与续练），首页不再堆记录卡，首屏减负。
- **首屏信息预算**：回到规范的"1 个问候 + 今日主卡 + 下一步卡 + 一组入口"，不超 2 个完整纵向区块。

### 5.2 统一入口组件

复用 `me` 页已有的 `SettingRow` 风格（图标 + 标题 + 副标题 + chevron），抽成通用 `AppListTile`，用于所有"进入某页"的入口，消除"卡片/按钮/区块"混用造成的视觉噪声。图标统一 20–24 线性、左 40 圆底、文字间距 6–8（符合 UI 规范 §1.4）。

### 5.3 底部导航不变

4 Tab（首页/历史/表达本/我的）保持。把"练习记录"明确收到 `history` Tab，首页不再承担记录展示，导航心智更清晰。

### 5.4 防误触

- 主色实心 CTA 每屏唯一；次要动作用 Secondary / Text / 列表入口，避免两个实心按钮相邻导致误点。
- 列表入口点击区 ≥56 高（规范），图标与文字留白充足。
- 打卡 chip 点按切换但**不触发跳转/不提交练习**，仅本地标记，避免误触改变学习状态。
- 对话页气泡操作行既有规范（朗读/重听贴左、翻译贴右、最小间距 8、不叠放）保持不变。

## 7 实现要点（落地时展开）

- **数据**：新增 `DailyCheckin` 表 + DAO + Repository + `checkinProvider` / `checkinCalendarProvider`（Drift 迁移 `schemaVersion +1`）。
- **自动判定**：`homeDataProvider` 已聚合按天活动，新增 `isCheckedInToday` 派生（session 活动 OR 当日 `daily_checkin` 存在）。
- **组件**：新增 `CheckinCard`（首页今日区）、`CheckinCalendarPage`（`/checkin`）、`AppListTile`（通用入口，抽自 `SettingRow`）。
- **路由**：`app.dart` 追加 `GoRoute('/checkin', …)`，ShellRoute 外，不改底部 4 Tab。
- **复用**：`streakDays` 连续天数、`targetMinutes` 目标、SessionRecord 聚合全部沿用，不另起统计。

## 8 验收标准草案

1. 完成一次对话/听写/复练/轻量后，首页打卡状态变"已打卡"，连续天数同步 +1（与现有口径一致）。
2. 用户手动勾选背单词/影子跟读后，当日视为已打卡，日历对应天亮起，且断网、无密钥也能记。
3. 打卡日历可查看当月每天学习构成与连续/最长统计；无分数/等级/勋章/推送/排名。
4. 首页重组后首屏聚焦"今日 + 下一步 + 统一入口"；"继续/最近/卡在哪"在 `history` 页可找到；核心练习 ≤2 次点击可达。
5. 一屏仅一个主色实心 CTA；列表入口统一形态、点击区 ≥56、不误触。
6. `flutter analyze` 0 error / 0 warning；`flutter test` 全绿；Web release 与 Android debug 构建通过。
