## 0. 安装包

- 调试包：`build/app/outputs/flutter-apk/app-debug.apk`（已在 2026-11-11 通过 `flutter build apk --debug` 生成；如已清理，重新执行该命令即可）。
- 安装方式（任选其一）：
  - 数据线连电脑，`adb install -r build/app/outputs/flutter-apk/app-debug.apk`；
  - 把 apk 传到手机，在「文件管理」里点开安装（需在系统设置里允许「未知来源应用」安装）。
- 首次进入会引导配置模型接口（与 MVP 一致）。

## 1. MVP 11 条回归（需求 §10.2，仍需真机逐条确认）

- [ ] 真机上完成一次「配置模型 → 选场景 → 对话 → 复盘 → 保存」完整闭环。
- [ ] 语音输入失败时，能改用文字继续，不重开会话。
- [ ] 翻译关闭时无中文；点按后出现中文，不自动朗读中文。
- [ ] 提示 L1–L4 都能用；任何一级都不会自动发送答案。
- [ ] 课后总结最多 3 条改法，每条有原句 / 改进句 / 原因 / 音频。
- [ ] 杀进程重启后历史、表达本、设置仍在；Key 不以明文出现在界面。
- [ ] 一次会话 ≥8 回合，AI 每次 ≤2 句且只问 1 个问题。
- [ ] 首段语音延迟达到 p50 ≤1.5s、p95 ≤3s（本地网络，目标值）。
- [ ] 手动把朗读引擎切成系统 TTS，会话仍完整可用。
- [ ] 单次会话成本可统计（含「估算」标记），且不超过设定上限。
- [ ] 不出现账号、支付、社交入口。

## 2. 二期 M5–M7（本地文件路线，已在代码侧验证）

- [ ] 首页「听写教材」栏目进入教材库；右上角「导入」能选本地音视频 + 对应 `.srt` / `.vtt`。
- [ ] GBK 字幕导入不乱码；超过 30 分钟的素材给出明确拒绝提示。
- [ ] 教材详情能逐句播放；手动「合并 / 拆分 / 微调起止 / 标太难」有效。
- [ ] 进入听写：片段裁剪播放在句子边界附近（首/尾允许 ±100ms 余量），0.75x 与 1.0x 切换有效，可无限复听。
- [ ] 提交后逐词差异正确：只改大小写或标点判全对；漏词明确标「漏写」；长词拼错按半词计；多写计入分母。
- [ ] 只改大小写/标点/多余空格 → 判为全对；阈值/缩写等价/数字等价在「设置 → 听写练习」调整后，听写页判分随之变化。
- [ ] 教材库显示已练句数与正确率；错句本跨教材汇总未通过的句子；「只练全部错句」和按教材「只练错句」都能进听写。
- [ ] 中途退出再进，回到上次那一句（单本与跨教材分别验证）。
- [ ] 「我的 → 数据与存储 → 清空听写素材」删除教材/句子/记录与音频副本；「清空所有数据」也包含二期内容；视频源文件仍在原处。
- [ ] 覆盖安装（v1→v2）后，原来的对话记录、表达本、场景仍在，二期新表不影响旧数据（可用 v1→v2 迁移测试佐证）。

## 3. 流程 C：链接导入（2026-11-11 新增，代码侧已验证）

- [ ] 导入页切到「链接导入」；填音视频直链 + 字幕链接，进度条随下载推进，成功后进入教材库。
- [ ] 粘贴一个**播客 RSS**（`.rss` / `.xml` / `.atom`）链接，自动解析 enclosure 音频与内嵌字幕并切句。
- [ ] 直链音频/视频且字幕留空时，自动尝试同站点同名 `.vtt` / `.srt`。
- [ ] 粘贴 **B 站 / YouTube / BBC** 等平台页面链接，导入明确提示「不抓取平台内容」并拦截，不崩溃、不静默失败。
- [ ] 链接格式非法（非 http(s)）或下载失败（404 / 超时）给出明确错误，不静默失败。
- [ ] 音频/视频下载后落盘到 App 私有目录，重启后仍能播放（与本地文件同路径处理）。
- [ ] 版权提示文案存在：只处理你有权使用的本地文件或直链（含播客 RSS），不抓取平台内容、不下载版权内容、不分享。

> 注意：Web 端浏览器受 CORS 限制，跨域链接可能无法直接下载，以 Android 真机为准。

## 4. 已知限制（验收时如实记录）

- 无字幕自动生成字幕（Q18 / 流程 B）仍未实现：无字幕时只给「后续开放」提示，无假入口。
- 平台专属下载器、端内转码、视频画面播放、逐词卡拉 OK 高亮均不在范围内。
- 语音首段延迟的真机实测值依赖设备与网络，清单只给出目标值。
