## 1 现状：素材够、单次闭环有，缺「这一个月怎么走」

| 已经具备 | 用户能感知到的 |
|---|---|
| 场景库（分类 / 难度 / 目标表达 / 每场 3 条小目标）+ 自建场景、课前 60 秒热身 | 选一个场合就能开聊，开场前知道要办成哪 3 件小事 |
| 10 分钟对话、分级提示、翻译开关、课后复盘（亮点 / 改法 / 表达 / 下次建议） | 练一次有完整反馈，改法可试听、可存表达本 |
| 90 秒开口练习、到期复练、表达本「已掌握」、错句本、教材听写 | 上次的错会回来，但要自己想起来点进去 |
| 首页「今天练这个」、周次数 / 分钟 / 连续天数、3 分钟轻量、近 4 周趋势 | 有活动量记录，也有单条推荐 |

**四个缺口**（对应调研报告断点 A / C / D）：

1. **没有阶段与目标**：除了「每天练几分钟」，说不清这个月要练成什么样。
2. **没有顺序**：场景越来越多，每次打开都要重新决定「今天练哪个」。
3. **没有完成标准**：每场 3 条目标只在本次复盘可见，练完说不清「这个方向算不算过了」。
4. **下一步没有解释**：「今天练这个」给了动作但没连到阶段进度；趋势图也不指向下一次该做什么。

结果就是用户反馈的迷茫感：**单次练得挺满，长期看不出方向**。

## 2 定位与边界

| 是 | 不是 |
|---|---|
| 给现有场景、表达、教材、复练内容排一个**可解释的阶段顺序** | 课程体系、课程大纲、课时排表、考试备考 |
| 按水平与目标生成计划，随练习表现持续校准 | 入门测评、CEFR 定级、分数 / 等级 / 能力雷达 |
| 一个阶段里 5–7 条轻量安排，可跳、可换序、可退 | 必须解锁的关卡、打卡、补作业、勋章 / 排行榜 |
| 打开 App 给一个「下一步」动作 | 每日推送提醒、AI 替你生成一套训练计划 |
| 复用已有内容与数据，不生产新内容 | 新建内容库、扩容场景、新增题库 |

**必须先说清的口径冲突**：

- 需求文档 §3.3 明确不做「系统课程 / 考试备考」，理由是课程重、容易变成「完成任务」；三期里程碑 §8 把「训练计划生成 / 每日提醒」列为范围外。
- 本方案按「**轻量阶段导航**」设计，恰好落在两条红线之间：不排课、不解锁、不考试、不推送，只是把已有素材按目标串起来。
- 若用户想要的是标准分级课程（按课时解锁、有测评定级、有课程列表），那属于**范围变更**，须先修订上述口径再实施。
- 保持不变：底部 4 个入口、场景库自由浏览、「随时开始、随时结束」的产品偏好；MVP 的 11 条验收清单不因本方案勾选；主指标仍是**连续 4 周、每周 ≥3 次、每次 ≥8 分钟**。

## 3 阶段性计划怎么「动态生成」

### 3.1 三个输入（首次 3 问，不考试）

1. **当前水平**：沿用设置里已有的 A2 / B1 / B2 / C1 自评；已有练习记录时改用最近几次的真实表现（能否说满 8 回合、用了几次参考答案、是否常开翻译、3 条目标达成几条），自评只作兜底。
2. **目标**：最想用得上的场合（工作 / 旅行 / 日常 / 综合）+ 一句具体诉求（例如「开会能追问和确认」「点单不卡壳」）；不设考试类目标。
3. **投入节奏**：每次 10 分钟、每周 3 次（可改 5 / 15 分钟，低能量日允许 3 分钟轻量）。

### 3.2 生成与更新（可见规则，理由可核对，断网也能用）

| 时机 | 发生什么 |
|---|---|
| 首次设定 | 由水平 + 目标选起点阶段，按目标从场景库筛出一批场景；**分类与场景数量按实际数据动态取，不写死**，场景库扩容后自动纳入 |
| 每次练完 | 依据「3 条目标达成 / 提示与翻译依赖 / 到期复练 / 上次卡在哪」把下一项排到最前，并在复盘末尾直接给出下一次入口 |
| 每周回顾 | 看本周节奏与达标情况，建议「继续 / 补一轮巩固 / 换难度」；不擅自跳阶段 |
| 阶段结束 | 给一次「阶段回顾」，据此进入下一阶段、再巩固一轮，或换目标重排 |
| 用户随时 | 改目标、改起点、换阶段、跳过某次安排；**跳过不锁后续、不补作业、不提醒**，历史与已巩固内容不丢 |

### 3.3 一个具体例子

> 起点 B1 ／ 目标「工作会议能追问和确认」／ 每次 10 分钟、每周 3 次 → 从「稳定表达」阶段开始：
>
> - 周一：会议澄清再练一次（带 3 条目标）→ 复盘 → 90 秒开口
> - 周三：到期的 2 条改法复练 → 同场景提高难度再聊一次
> - 周五：换一个工作类场景 → 一段真实语速教材听写
>
> 每次结束都直接给出「下一次练这个」；周日回顾若 3 条目标连续达成、很少开翻译，就建议进入「场景拓展」。

## 4 四个阶段：目标 / 内容范围 / 推荐顺序 / 完成标准

> 阶段不是关卡：不设固定周数，按完成标准推进；只显示「已达成 / 待练」，不给分数、等级或百分比。完成标准只回答「可以往前走了吗」，不是考核。

### 阶段 1 · 开口起步（把第一句说出来）

- **学习目标**：开场不卡，能独立说满一次完整对话。
- **内容范围**：难度较低、回合较短的日常类场景；每场的 5 条目标表达与 3 条小目标；课前 60 秒热身可选；翻译默认关，卡住优先用重听 / 关键词台阶。
- **推荐顺序**：热身（可跳过）→ 10 分钟对话 → 复盘只挑 1 个重点 → 90 秒开口 → 次日复练。
- **完成标准**：连续 3 次会话都达到 ≥8 回合、3 条目标中 ≥2 条达成、参考回答使用 ≤3 次；复练里已有若干条进入「已巩固」；表达本存下 ≥6 条。

### 阶段 2 · 稳定表达（少靠提示和翻译）

- **学习目标**：不依赖翻译和参考答案把熟悉的场景聊完，上次改过的说法能再用出来。
- **内容范围**：同一批场景的第二次练习 + 与目标相关的工作 / 社交类场景；意外追问、提高难度、换角度追问。
- **推荐顺序**：先清到期复练 → 同场景再练一次并加压 → 复盘对比上次 → 把改法送回复练队列。
- **完成标准**：最近 3 次翻译查看 ≤30%、参考回答 / 中→英 ≤1 次；上次改法在后续对话里用对；保持每周 ≥3 次、每次 ≥8 分钟。

### 阶段 3 · 场景拓展（换个场合也说得出来）

- **学习目标**：把同一能力迁到不同分类，并开始听懂真实语速。
- **内容范围**：按目标筛出的多个分类场景 + 教材库听写 + 错句本「只练错句」+ 3 分钟轻量日。
- **推荐顺序**：新场景 → 复盘 → 表达本 → 一段教材 → 错句复练 → 换分类。
- **完成标准**：目标相关的分类都练过、每个场景 3 条目标 ≥2 条达成；错句二次通过；近 4 周「提示使用率 / 改法复现率」趋势稳定向好。

### 阶段 4 · 自主运用（自己定方向）

- **学习目标**：自己定场合、撑住长回合，并能说清自己的薄弱项、自己安排巩固。
- **内容范围**：自建 / 一句话生成的场景、真实语速教材、深一层追问、低能量日 3 分钟轻量。
- **推荐顺序**：自己挑本周重点 → 长回合对话 → 复盘只留 1 条重点 → 巩固 → 阶段回顾。
- **完成标准**：高难场景连续达标、3 条目标全部达成；薄弱项有「再练对」的证据；月度自评「敢开口」≥4/5。

## 5 进度追踪：看得见，但不打分

| 元素 | 给用户的东西 |
|---|---|
| **路径页三问** | 我现在在哪（阶段名 + 一句话目标）／走到哪了（本阶段已完成几次、还有几条待练、多少改法已巩固）／接下来做什么 |
| **阶段安排清单** | 当前阶段拆成 5–7 条可直接点开的安排，各带状态（未开始 / 进行中 / 已完成 / 待巩固）与推荐顺序；完成一条自动指向下一条。**是轻量清单，不是任务体系**：可跳过、可换序、不解锁、不打卡 |
| **阶段回顾** | 三个出口（进入下一阶段 / 再巩固一轮 / 换目标重排），并用三条证据说明为什么：哪几次达标、哪些改法已巩固、趋势怎么变；每项可点开看「怎么算的」 |
| **口径一致** | 与首页周次数 / 分钟 / 连续天数、3 分钟轻量「不计入主指标」保持同一套数；断档几天不惩罚、不打负向标记，回归时给轻量入口或「接着上次」 |

**让已有数据说话**（功能层面的补齐）：把每次复盘的 3 条目标自评汇成阶段进度；让表达本「已掌握」与复练「已巩固」在路径里可见；统一「设置里的水平」与「场景难度标签」的口径，使难度推荐说得通；把目前没有界面入口的练习阈值补上可见说明。

**仍然不做**：总分、CEFR 定级、能力雷达、薄弱项热力图、勋章、连胜、排行榜、每日推送。同类产品的差评恰恰是「进度追踪差、课程列表乱」——问题不在图表多少，而在指标有没有连到下一步动作。

## 6 下一步行动指引（缓解迷茫的关键）

| 位置 | 给什么 | 关键细节 |
|---|---|---|
| 首页 | 「下一步」卡（由「今天练这个」升级） | 一句话今天做什么 + 一句可核对的理由（上次用了 4 次提示 / 有 3 条到期 / 本阶段还差 2 次）+ 一键开始 + 「换一个 / 今天先跳过」；无历史时给「随便来一段」而不是空白；≤2 次点击开练 |
| 复盘末尾 | 3 条目标达成结果 → 直接给下一次入口 | 未达成那条可「只练这条」；有到期改法优先复练；同场景可「提高难度再聊一次」 |
| 场景库 | 「适合当前阶段」标记 | 只是提示，不隐藏、不置灰其它场景，自由浏览始终可用 |
| 低能量日 | 3 分钟轻量入口 | 作为「今天最小可完成」，保持连续感，但不冒充一次完整练习 |
| 断档回归 | 「接着上次 / 从轻量开始」 | 不显示「已中断 N 天」，不要求补练 |
| 设置 | 改目标 / 改起点 / 重排路径 | 只重排计划，不重置历史与已巩固内容 |

**统一原则**：每条指引都要带**理由**、带**一个可点开的动作**、带**一个退出选项**；理由必须能对上用户自己的记录，避免「App 替我决定」的黑盒感。

## 7 同类产品思路：借什么、不借什么

| 同类做法 | 值得借 | 本项目不借 | 落到哪里 |
|---|---|---|---|
| 分级课程体系 | 难度与内容有梯度、阶段有出口 | 课程大纲、课时解锁、考试备考、新内容生产 | 用场景难度 + 分类做四阶段梯度，素材仍是现有场景 / 表达 / 教材 |
| 每日任务 | 「今天只做一件明确的事」 | 打卡、连胜、推送提醒、复杂任务体系 | 下一步卡 + 到期复练 + 3 分钟轻量入口 |
| 能力评估 | 用真实表现持续校准难度 | 入门测评、CEFR 定级、分数 / 雷达 / 热力图 | 自评 + 最近几次的目标达成 / 提示与翻译依赖 / 巩固情况 |
| 路径推荐 | 替用户挑一个，降低选择成本 | AI Agent 生成训练计划、云端个性化 | 可见可解释的规则，理由与数据对得上，用户可换可跳 |
| 目标通关 | 通关绑定「有没有办成那件事」 | 分数、评级、星级 | 复用每场 3 条目标与「已达成 / 待练」自评 |

场景越多越要把入口收口到「下一步」一张卡；路径页展示的是**方向**，不是又一份需要从头刷到尾的课程列表。

## 8 分期落地建议（按价值排序，不写工期）

| 批次 | 做什么 | 做完用户会感到 | 怎么判定有效 |
|---|---|---|---|
| **1 先解迷茫** | 起点 3 问、四阶段模板最小版、路径页（三问 + 阶段安排 + 下一步）、复盘目标达成汇成阶段进度 | 打开 App 不用做选择题，知道今天练什么、为什么 | 首次打开到开始练习 ≤2 次点击；能当场回答「我在哪 / 今天干嘛 / 还差什么」；下一步卡的理由与记录对得上 |
| **2 阶段闭环** | 阶段回顾三态出口、换目标重排、场景库阶段标记、断档回归与低能量日入口 | 练到一段落后有人告诉我「可以往前了 / 再稳一轮」 | 达标后给出下一阶段建议且不阻塞；跳过、换序、换阶段都能继续练；断档无惩罚入口 |
| **3 持续校准** | 按练习表现调整阶段内顺序、把教材听写与错句本并入拓展阶段、趋势两条作为回顾证据 | 路径越来越贴自己的薄弱项，而不是一张固定课表 | 连续使用 4 周后推荐内容与近期薄弱项一致；主指标（每周 ≥3 次、每次 ≥8 分钟）不因路径改版下降 |

**每批都要过的护栏**：不改 MVP 11 条验收；不新增课程 / 题库 / 内容库；不出现分数、等级、排行榜、勋章、推送；不把场景库变成必须按顺序刷的清单；推荐仍沿用现有可解释的方式，断网、无模型密钥时路径与进度照样可看。

## 9 需要拍板的问题

| # | 问题 | 建议默认 |
|---|---|---|
| Q1 | 学习路径是否进入需求范围？与「不做系统课程」「训练计划生成列为范围外」如何界定 | 按「轻量阶段导航」进入，非课程；若要做标准分级课程，先改范围 |
| Q2 | 起点怎么定 | 自评 + 最近几次真实表现；**不做入门测评、不打分**；是否加一次 3 分钟摸底对话另议 |
| Q3 | 阶段要不要解锁 | 不解锁，可跳可退；完成标准只是「建议往前走」 |
| Q4 | 目标维度 | 工作 / 旅行 / 日常 / 综合 + 时长与频次；不做考试类目标 |
| Q5 | 完成标准怎么呈现 | 「已达成 / 待练」+ 可核对的次数与证据，不折算分数或百分比 |
| Q6 | 是否允许自动调整顺序 | 允许，但每次调整都要给出理由，且可手动改回 |
