## 1. 隔离原则（本轮硬约束）

1. **不改 MVP 的验收口径**：需求 §10.2 的 11 条清单保持未勾选；M0–M4 章节、§12 场景扩容、§13 续练、§14 对话体验优化的记录一律不改。
2. **不改底部 4 Tab、不改对话状态机**：新页面挂在 `ShellRoute` 外，首页用栏目入口；`ConversationController`、`HintRail`、复盘链路零改动。
3. **不动全局朗读播放器契约**：`AudioPlayerService.playBytes/playPath` 的「等待播放完成才返回」语义是 TTS 状态的基础；听写用独立片段播放器实例，进入听写前只调用既有 `stop()`。
4. **老数据零丢失**：SQLite 从 v1 升 v2，`onUpgrade` 只 `createTable` 新表，不 `ALTER`/`DROP` 老表；覆盖安装不清数据仍能续练、记录与表达本仍在。
5. **判分离线**：判分是纯 Dart 词级 diff，不调用模型接口、不联网；需求 §12.6 的模型配置只用于已有的表达本 / TTS，不进入判分链路。
6. **合规边界**：只处理用户自己选的本地文件，App 不下载、不抓取、不分发、不做 DRM；页面内保留「素材版权归原权利人，仅供个人学习」声明。

## 3. 二期开放问题的执行口径（需求 §12.8）

> 用户下达「开始执行二期计划」，以下按需求表格的**当前默认**执行；若用户推翻任一项，只改本节、技术补充文档与对应实现，不改 MVP 范围。

| # | 决策 | 本轮执行口径 |
|---|---|---|
| Q13 | 素材来源 | **只做本地文件**；链接导入不实现 |
| Q14 | 自己准备素材 | **接受**，App 内不搜索、不下载 |
| Q15 | 判分严格度 | **标准**：忽略大小写/标点/多余空格、缩写与数字双向等价、长词（≥6 字母）编辑距离 1 记「拼错」并半计分、默认 90% 通过；规则在界面可见且阈值可调 |
| Q16 | 是否保留视频画面 | **只音频**，不复制整个视频文件；片段按时间轴裁剪播放，不落地片段文件（预研明确避开端内转码） |
| Q17 | 单集时长上限 | **30 分钟**，超出在导入时明确拒绝 |
| Q18 | 无字幕 ASR | 属流程 B（二期第二阶段，需实测接口与端侧模型），**本轮不实现**；无字幕时给出「可自动生成字幕（后续开放）」的提示，不做假入口 |

**已知实现偏差（相对需求 §12.5 F11 的字面表述）**：需求写「只保留抽取出的音频片段与文本」，预研 §1/§6 又要求避开端内转码。本轮取「零转码」优先：纯音频源文件复制到 App 私有目录，视频源文件只记录路径不复制，句子片段由播放器按起止时间裁剪、不导出片段文件。理由与影响写入技术补充文档。

## 4. M5 导入与切句

**目标**：把用户本地的音视频 + 字幕变成一份可逐句播放、可手动修正的教材。

### 4.1 任务

| # | 任务 | 模块 | 交付物 | 点数 |
|---|---|---|---|---|
| T5.1 | 二期里程碑与技术补充文档 | `docs/` | 本文档 + 技术补充文档 + `AGENTS.md` 索引 | 2 |
| T5.2 | 数据模型与 schema v2 | `data/db`、`domain/models` | `material` / `material_segment` / `dictation_attempt` 三表、模型、`onUpgrade` 只建新表、双端 `LocalStore` 实现、`clearAll` 接线 | 3 |
| T5.3 | 字幕解析与切句纯逻辑 | `features/dictation/ingest`、`align` | SRT/VTT 解析（UTF-8 / UTF-8 BOM / GBK）、30 分钟上限、脏行过滤、按标点切句与 3–12 秒 / 5–22 词约束、边界余量、去重 | 3 |
| T5.4 | 纯逻辑单元测试 | `test/` | 字幕解析、切句合并/拆分、编码回退的断言 | 1 |
| T5.5 | 导入页、教材库、教材详情 | `features/dictation/pages` | 选文件、解析进度、失败原因、重复导入提示、句子列表、手动合并/拆分/微调起止点、版权声明 | 3 |
| T5.6 | 路由与首页入口 | `app/app.dart`、`features/home` | `/materials`、`/materials/import`、`/materials/:id` 三条 `ShellRoute` 外路由 + 首页栏目区块 | 1 |

### 4.2 交付物

可导入一份带字幕的本地素材，生成句子列表与时间轴，并能对句子做手动修正；原有场景对话、记录、表达本、设置完全不受影响。

### 4.3 验收标准（逐条当场判定）

1. 导入一份 10 分钟内素材 + `.srt`，解析在 60 秒内完成，教材详情显示句数与预计时长。
2. UTF-8、UTF-8 BOM、GBK 三种字幕都能正确读取，中文/英文文本无乱码；`.vtt` 也能导入。
3. 字幕损坏、格式不支持、超过 30 分钟、未选字幕四种情况都有明确原因与下一步提示，不崩溃、不产生半成品教材。
4. 同一素材重复导入提示「已存在」，教材库不出现副本。
5. 自动切出的句子可逐句播放；`[Music]` / 掌声 / 纯标点行不进入句子列表；相邻重复句被去掉。
6. 手动合并、拆分、微调起止点后立即生效，不需要重新导入；句子序号与时间轴连续。
7. 覆盖安装旧版本（不清数据）后，原有会话、表达本、场景数、密钥仍在；新表可用。

### 4.4 风险点

| 风险 | 缓解 |
|---|---|
| 升版本与「不升版本自动加内容」的既有卖点冲突 | `onUpgrade` 只 `createTable`，`README` 明确区分「场景种子靠幂等 upsert」与「新表靠迁移」 |
| `LocalStore` 是抽象接口，漏改 Web 实现会编译失败 | 两端实现与 `clearAll` 同一次改动内补齐 |
| 视频源文件被用户移动 / 删除 | 详情页检测可访问性并提示重新导入；纯音频复制到私有目录 |

## 5. M6 听写与判分

**目标**：听一句、写一句、当场看到差在哪，全程离线可判分。

### 5.1 任务

| # | 任务 | 模块 | 交付物 | 点数 |
|---|---|---|---|---|
| T6.1 | 判分纯逻辑 | `features/dictation/scoring` | 规范化（大小写/标点/空格/弯引号/连字符）、缩写与数字双向等价、词级 LCS diff、四类逐词标记、长词编辑距离 1、可解释正确率、通过阈值 | 3 |
| T6.2 | 判分单元测试 | `test/` | 大小写标点、漏词定位、`I would like` vs `I'd like`、数字等价、长词拼错、阈值边界、离线无网络依赖 | 1 |
| T6.3 | 独立片段播放器 | `services/audio/clip_player.dart` | 按起止时间裁剪播放、0.75x / 1.0x、无限复听、播放状态与进度、页面退出释放；不改全局播放器 | 3 |
| T6.4 | 听写页 | `features/dictation/pages/dictation_page.dart` | 不泄露原文、弱提示只给词数、键盘输入、上一句/下一句、标记「这句太难」、中途退出回到上次句子、显示答案、逐词差异、复听、存表达本 | 3 |
| T6.5 | 判分配置与规则可见 | `domain/models`、`defaults.dart`、`settings_page.dart` | 通过阈值、缩写等价、数字等价、默认播放速度四项配置与「判分规则」说明 | 1 |
| T6.6 | 听写记录落库 | `dictation_attempt` | 每次提交保存输入、正确率、是否通过、逐词差异 JSON | 2 |

### 5.2 交付物

从教材详情两次点击内进入听写，完成「听 → 写 → 判 → 看差异 → 复听 → 收藏 → 下一句」闭环。

### 5.3 验收标准

1. 从教材详情到听见第一句 ≤2 次点击；显示答案前页面任何位置都不出现原句文本。
2. 复听不产生网络请求；同一句连点 3 次复听都能从片段起点重新播放；0.75x 可切换。
3. 只改大小写 / 标点 / 多余空格 → 判为全对；漏一个词 → 逐词结果准确指出漏词位置并标「漏写」。
4. `I would like` 与 `I'd like`（开启缩写等价）、`10` 与 `ten`（开启数字等价）不判错；关闭等价后按配置判错，规则在界面可见。
5. 长度 ≥6 的单词错 1 个字母标「拼错」而不是「漏写 + 多写」；正确率能按「正确词数 / 参考词数」解释清楚。
6. 断网 / 无模型密钥时判分仍可用；判分不写入对话历史、不生成复盘、不改首页今日分钟与连续天数。
7. 中途退出再进入回到上次的句子，已提交记录仍在。

### 5.4 风险点

| 风险 | 缓解 |
|---|---|
| 全局播放器与听写播放器同时出声 | 听写页 `initState` 停全局 TTS，页面 `dispose` 释放独立播放器 |
| 片段播放精度随解码器漂移 | 前后各留 100ms 余量；验收只要求首尾音不被明显切掉，不做逐词高亮 |
| 判分规则过严打击积极性 | 默认 90% 通过 + 拼写半计分 + 规则可见 + 阈值可调 |

## 6. M7 教材库与复练

**目标**：练到哪、错在哪都能追溯，错句可以集中复练。

### 6.1 任务

| # | 任务 | 模块 | 交付物 | 点数 |
|---|---|---|---|---|
| T7.1 | 教材库统计与句子状态 | `features/dictation/pages/material_library_page.dart` | 标题、时长、句数、已练句数、正确率；单集句子状态（未练 / 已通过 / 有错） | 2 |
| T7.2 | 错句本与只练错句 | `/materials/wrong`、`MaterialRepository` | 跨教材汇总最近一次未通过的句子、顺序稳定、一键只练错句 | 3 |
| T7.3 | 删除与缓存清理 | `LocalStore`、`data_settings_page.dart` | 删除教材级联删句子与听写记录并清理私有目录音频；「清空所有数据」包含二期数据；独立「清理听写素材」入口 | 2 |
| T7.4 | 全量回归与文档同步 | 全部 | `flutter analyze` / `flutter test` / `flutter build web --release --no-web-resources-cdn`、MVP 回归清单、6+ 份文档同步 | 1 |

### 6.2 交付物

教材库、错句本、复练入口、清理能力，以及一份逐条通过的回归记录。

### 6.3 验收标准

1. 重启 App 后教材进度、正确率、错句本与听写记录仍在。
2. 「只练错句」只筛出最近一次未通过的句子，顺序与错句本一致；练过通过后从错句本移除。
3. 删除教材后，相关句子与听写记录查不到，私有目录中的音频副本确实被删除。
4. 「清空所有数据」后教材库为空、错句本为空；MVP 的场景、密钥、设置行为与改动前一致。
5. `flutter analyze` 0 error / 0 warning；`flutter test` 全通过；Web release 构建通过；覆盖安装不清数据可启动。
6. 对照需求 §10.2 的 11 条 MVP 清单逐条回归，无一条因二期改动而失败。

### 6.4 范围外（本轮明确不做）

流程 B（无字幕自动 ASR 生成）、平台下载器与批量爬取、素材分享 / 导出 / 教材市场、DRM、端内转码与抽音轨、视频画面播放、逐词卡拉 OK 高亮与音素级评分、AI 讲解与同义改写判分、多语言、云端同步。

### 6.5 M8 链接导入（2026-11-11 补，流程 C）

- 覆盖能力：F11 的「链接来源」分支。
- 实现：`MaterialImportService.importFromUrl(mediaUrl, subtitleUrl?, title, onProgress?)` 用 `dio` 下载音视频 + 字幕，随后复用与本地文件完全相同的 `_createMaterial`（字幕解析 → 切句 → 落库）；非 Web 端下载的音视频写入 App 私有目录，与本地文件同等待遇。导入页新增「链接导入」模式（两个 URL 输入框 + 进度条）。
- 验收（代码侧）：`test/url_import_test.dart` 用假 `HttpClientAdapter` 拦截 Dio，验证「下载→解析→切句→落库」与「空字幕明确报错」；`AndroidManifest` 已具备 `INTERNET` 权限。
- 范围外：平台专属下载器 / 抓取、端内转码；Web 端跨域链接受 CORS 限制，以 Android 真机为准。
- 真机验收见 [真机验收清单](device-acceptance-checklist-v0.1.md) §3。
