# 动机强化设计（战报 + 三档粗评 + 旅程地图）v0.1

状态：已拍板（2026-11-16），待实施。
适用范围：M16。本文是「学习路径（M14）→ 每日打卡（M15）」之后的动机层设计，只补「方向感与成绩感」，不改变任何学习内容与训练顺序。

## 0. 拍板记录（2026-11-16，用户逐条确认）

| 争议点 | 拍板结论 |
|---|---|
| 成绩感的形式 | **战报式**：每次练完给「3 件小事 N/3 + 求助证据 + 一句亮点」的可核对成绩块，不做数字分 |
| 路线图的机制 | **全节点可点、不锁定**：只学多邻国的视觉方向感，不学解锁/置灰/闯关 |
| 使用对象 | **成人自驱**为主；挫败风险容忍度高于儿童，但仍不使用数字分 |
| 要不要评分 | **三档粗评**（顺畅 / 稳住 / 吃力），替代数字分；仅作参考，重点看周趋势不盯单次 |

## 1. 背景

- 学习路径（M14）已能回答「我在哪 / 接下来做什么」，但形态是文字卡片列表 + 4 点梯度条，没有「往前走」的地图感。
- 每次对话与复盘的反馈偏散文化（亮点 / 改法 / 小事勾选），没有一眼可读的「成绩」，成人用户缺少即时成就感。
- 需求非目标与调研报告红线：**不做分数、百分制、CEFR 等级、星级、排行榜、勋章、连胜、解锁式关卡**（调研：误判分数毁信任、分数 ≠ 真实能力、多巴胺循环不产出）。本次仍严格遵守；三档粗评是「定性判定」而非分数。

## 2. 功能设计

### 2.1 复盘战报卡（成绩感）

- 复盘页顶部「练习完成」渐变卡升级为**战报卡**，练完一眼看到成绩：
  1. **三档粗评**（见 2.2）：档位大字 + 一句判定依据；
  2. **3 件小事 N/3**：全部达成时显示「3 件小事 全部办成」；
  3. **求助证据**：提示 N 次 · 有辅助 N 回合 · 翻译 N 次（原样保留，可核对）；
  4. 时长 / 开口 / 提示三指标与成本行保留。
- 战报卡是**快照**；本场目标卡（可勾选）仍是明细与修正入口，勾选后战报 N/3 同步刷新。
- 全部由本地数据 + 复盘解析结果构成，LLM 判定缺失时只缺档位行，其余照常。

### 2.2 三档粗评（替代数字分）

- 档位固定三档：**顺畅 / 稳住 / 吃力**，外加一句中文依据（≤20 字）。
- 判定方式：复盘生成时由模型对整场会话**整体判定**输出「表现」段（`表现: <档位> || <依据>`），依据对话全貌（独立性、连贯性、目标达成），不逐句打分。
- 语义（成人口径）：
  - **顺畅**：基本独立完成，表达连贯，3 件小事基本办成；
  - **稳住**：聊完了，但有求助（提示/翻译/参考回答）或较多磕绊；
  - **吃力**：大量依赖辅助或难以完成对话。
- 硬性约束：
  - **任何位置不出现数字、百分制、星级、雷达**；档位就是全部成绩刻度；
  - 判定失败 / 缺段时**不显示档位、不降级复盘**（与目标判定同一条容错口径）；
  - 文案强调「只作参考，看趋势别盯单次」；后续如需周聚合（近 5 次档位分布）另立任务，本期不做。

### 2.3 学习路径旅程地图（方向感）

- 路径页顶部的 4 点梯度条升级为**蛇形旅程地图**（竖向 S 形路径，可滚动）：
  - **节点 = 阶段头（4 个，大节点）+ 阶段内安排条目（每阶段 5–7 个，小节点）**，一条路从「开口起步」走向「自主运用」；
  - 状态渲染：已完成 = 主色实心 + 对勾；待巩固 = 白底警示描边；今天跳过 = 弱化描边；未开始 = 白底描边；**下一步节点 = 光晕高亮（"你在这里"）**；
  - 阶段头显示阶段名 + 已完成 n/m。
- **机制红线**：全节点可点、不锁定、不置灰、不出现锁图标、不出现分数；未来阶段的条目照样可点可跳（与「阶段不是关卡」一致）。点阶段头 = 切换当前阶段（与原梯度条行为一致），点条目 = 进入对应练习。
- 详情不重复：地图是总览；当前阶段的「阶段安排」清单（含理由、按钮）保留在下方。
- 数据零新增：节点状态全部由既有计划计算（`computeJourneyStages`，纯函数，离线可用）。

### 2.4 「还差 N 件」进度行（常驻方向感）

- 下一步卡（首页 / 复盘 / 路径页共用）在理由下增加一行 caption：**「第 N/4 阶段 · 本阶段还差 M 件」**；M = 当前阶段安排里未完成（pending + 待巩固）条数；全部走过时改为「本阶段安排都走过了」。

## 3. 明确不做（本期与后续默认都不做）

数字分 / 百分制 / CEFR 等级 / 星级 / 能力雷达 / 排行榜 / 勋章 / 连胜 / 解锁与置灰 / XP 积分 / 社交对比 / 每日推送。

## 4. 失败降级与边界

| 场景 | 行为 |
|---|---|
| 复盘模型没输出「表现」段或档位不合法 | 战报卡不显示档位行，其余照常；复盘不算 degraded |
| 目标判定缺失 | 战报 N/3 隐藏，目标卡退回纯自评文案 |
| 学习路径未配置 | 不渲染旅程地图（维持现状引导） |
| 场景库极小 | 地图节点不足时按实际条目渲染，不补占位节点 |
