## 1. 隔离原则（本轮硬约束）

1. **不改验收口径**：需求 §10.2 的 11 条 MVP 清单保持未勾选；二期 M5–M8、三期 M9–M12 的验收标准不变。
2. **不动主链路**：不改底部 4 Tab、不改 `ConversationController` 主对话状态机、不改复盘生成主流程与提示词；新页面挂 `ShellRoute` 外，入口插在首页卡 / 设置 / 复盘 / 场景库。
3. **零改表**：路径状态 JSON 存 `app_meta` 单键，`schemaVersion` 保持 3，`LocalStore` 抽象与 drift / web 双端实现、`clearAll`、生成文件全部不动；清空数据后回到未配置空态。
4. **不新增网络与依赖**：阶段生成、完成判定、下一步推荐全为纯 Dart 规则；不调用 `/chat/completions`，断网 / 无密钥时路径与进度仍可看。
5. **不引入分数**：不做 CEFR 定级、能力雷达、热力图、总分、星级、排行榜、勋章、连胜、推送；完成标准只用「已达成 / 待练」+ 可核对次数与证据。
6. **不解锁**：4 个阶段都可点、可跳、可退；阶段安排可换序、可跳过，跳过不锁后续、不补作业。
7. **不新建内容**：不新增场景、不新增课程 / 题库 / 大纲；内容范围按 `builtinScenarios` 实际数据动态筛，数量与分类不写死。
8. **口径一致**：主指标仍是连续 4 周每周 ≥3 次、每次 ≥8 分钟；3 分钟轻量仍计入今日分钟、不计入每周有效次数。
9. **文档与代码同批**：UI 规范先改，需求 / 技术设计 / 开发文档 / 索引同一次改动完成；截图归档 `docs/shortscreen/M14/`、文件名带序号。
10. **状态容错**：KV 解码全部可空兜底 + try/catch；坏值、旧值、未配置都回落到可用空态，不崩、不显示半成品。

## 3. 交付物

首次打开可完成 3 问并生成四阶段路径；路径页回答「我在哪 / 走到哪了 / 接下来做什么」；首页、复盘、场景库、设置四处都能看见下一步；阶段达标后给三态出口且可解释。原有会话、复盘、表达本、教材、复练、密钥、设置与底部 4 Tab 完全不受影响。

## 4. 验收标准（逐条当场判定，不替代 §10.2）

1. 首次打开完成 3 问生成路径；改目标 / 改起点只重排计划，历史练习、表达本、复练与已巩固内容不丢。
2. 路径页当场能回答三问；阶段安排 5–7 条，每条可点开、有状态、可跳可换序；4 个阶段都可点，界面无锁图标 / 「未解锁」/ 分数 / 等级 / 百分比。
3. 首页「下一步」卡理由与记录对得上（到期复练数 / 上次提示次数 / 本阶段剩余条数），打开到开始练习 ≤2 次点击；无历史数据给可用入口；「换一个」「今天先跳过」即时生效且可改回。
4. 每阶段可见目标、范围、顺序与完成标准；达标后给下一阶段建议但不阻塞继续练；阶段回顾三条证据均可点开看「怎么算的」，样本不足显示「样本不足」不补 0。
5. 复盘末尾、场景库阶段标记、设置入口、断档回归与 3 分钟轻量入口均可用；场景库仍可自由浏览全部场景。
6. 清空练习数据后路径回到未配置空态、不残留旧进度；断网 / 无模型密钥时路径与进度仍可查看；未配置路径时首页回落原「今天练这个」规则。
7. `flutter analyze` 0 error / 0 warning；`flutter test` 全通过；Web release 与 Android debug 构建通过；对照 §10.2 11 条与 M5–M12 验收逐条回归无失败。
8. 截图归档 `docs/shortscreen/M14/`，文件名带序号；工作记录 `.logs/milestone-14.md`。

## 5. 风险点

| 风险 | 缓解 |
|---|---|
| 路径变成「必须刷完的课程表」 | 不解锁、可跳可退、断点回归不惩罚；文案只用「建议往前走」，不做完成率考核 |
| 状态 JSON 坏值导致页面崩溃 | 全字段可空兜底 + try/catch；无配置回落空态；Provider 失效清单集中管理 |
| 新增 Provider 缓存旧进度 | 所有写入经 `writePath` 统一失效；复盘目标自评、数据清空、会话完成处补失效 |
| 场景数量 / 分类变化后计划失效 | 内容范围按实际数据动态筛选，不写死数量；找不到匹配场景时回落到全库排序，不出现空计划 |
| 完成标准被误读成分数 | 只用「已达成 / 待练」与真实次数；复用既有 3 条目标自评与两条可解释趋势，不新增评级 |
| 首页多出第二个主色 CTA | 「下一步」卡沿用既有卡位升级（替换而非叠加）；复盘紧凑卡只用次按钮；路径页一屏一个主 CTA |
